Deep dive

Case study — moving millions of records between tenants.

How the Skedulo Data Loading tool migrates large datasets between environments without freezing the app.

Problem

Customers needed to move large volumes of configuration and record data between tenants — for example staging to production — safely, instead of copying it by hand.

Constraints

Datasets can reach millions of records. The tool couldn't block the UI or hold everything in memory, and had to fit the existing NestJS and AWS stack.

Approach

An asynchronous export/import pipeline. Work is streamed in bounded batches and queued, so throughput scales without locking the user's session.

Outcome

Migrates millions of records between tenants without interrupting users, and a Playwright suite keeps regression effort down for the QA team.

// Stream records in bounded batches so a multi-million-row
// migration never blocks the event loop or the user's session.
async function migrate(source: Tenant, target: Tenant) {
  for await (const batch of exportInBatches(source, { size: 500 })) {
    await queue.enqueue('import', { target: target.id, batch });
  }
}
