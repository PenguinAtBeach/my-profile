# my-profile

Personal portfolio site for Tran Tuan Phuong — Senior Full-Stack Engineer.

Hand-coded single-page site: `index.html` (no build step). Includes a command
palette (⌘K), a Data Loading case study, animated stats, an availability panel,
and a dark/light theme.

## Deploy
Any static host works. For GitHub Pages: Settings → Pages → deploy from `main` → `/root`.
